本書は AI家庭教師（ai-math-tutor）のカスタマーサポート対応マニュアルです。

## 1. 端末登録上限（2台制限）の解除手順

### 背景
ユーザーが機種変更やブラウザのキャッシュ削除、端末初期化等を行った場合、古い端末セッションが残り「登録できる端末数（2台）の上限に達しました（device_limit / device_not_bound）」エラーが発生することがあります。

### 本人確認手順
端末解除を実施する前に、以下の情報で本人確認を行います:
1. 購入時に登録したメールアドレス
2. Stripeの決済情報（請求書ID、または直近の決済日、カード下4桁）
※ ライセンスキーそのものをメール本文で送らせないよう案内してください。

### 解除コマンド（管理者操作）
サーバー管理スクリプト `unlink-device.mjs` を実行します:

```bash
cd server

# 例1: ユーザーのメールアドレスを指定して全端末登録をリセット（推奨）
node scripts/unlink-device.mjs --remote --email user@example.com --all

# 例2: ライセンスキーを指定して全端末解除する場合
node scripts/unlink-device.mjs --remote --license-key AMT-XXXX-XXXX-XXXX-XXXX --all

# 例3: 特定の端末IDのみを解除する場合
node scripts/unlink-device.mjs --remote --email user@example.com --device-id <DEVICE_ID>

# 例4: Staging 環境でテストする場合
node scripts/unlink-device.mjs --remote --staging --email test@example.com --all
```
※ 実行結果には削除された件数のみ（例: `Unlinked 1 device(s).`）が出力され、端末ハッシュ値や秘密情報は画面に一切表示されません。

### ユーザー側の再登録・再バインド手順
端末解除が完了した後、ユーザーに以下の手順でアプリから再登録していただきます:
1. アプリ（数学または英語）を開く。
2. 画面右上の **⚙️ 設定** を開く。
3. すでにキーが入力されている場合は、一度 **「ライセンス解除」** をクリックしてローカル認証情報をクリアする。
4. お手元のライセンスキー（`AMT-XXXX-XXXX-XXXX-XXXX`）を貼り付ける。
5. **「保存」** をクリックする（自動的に `/v1/redeem` が呼ばれ、現在の端末が新しいスロットにバインドされます）。
6. 問題を1問解き、AI解説が正常に生成されることを確認する。

## 2. ライセンスキー紛失・再送の案内

ユーザーがライセンスキーを紛失した場合:
1. ユーザー自身で再送ページから手続き可能であることを案内します。
   - 再送ページURL: `https://g4pjo75-gif.github.io/ai-math-tutor/site/recover.html`
2. 自動再送が届かない場合（迷惑メール設定等）は、本人確認のうえStripeセッションIDからキーを再導出して案内します。

## 3. 解約・支払い方法変更の案内

解約およびクレジットカードの変更は、ユーザー専用のカスタマーポータルから行えます:
- ポータルURL: `https://g4pjo75-gif.github.io/ai-math-tutor/site/portal.html`
- またはアプリ内設定画面の「💳 契約管理」ボタンから遷移できます。

---

## 4. 個人情報開示・削除（GDPR / APPI対応）手順

ユーザーから個人情報削除（利用停止・データ消去）の請求があった場合の手順:

1. 本人確認を実施。
2. Stripe側で定期購読を解約（即時キャンセル）。
3. D1データベース上の該当レコードを削除:
   - `licenses` テーブルの当該メールアドレス・ライセンスレコード
   - `devices` テーブルの関連レコード
   - `usage` テーブルの履歴
4. 処理完了後、ユーザーへ削除完了通知を送付。
