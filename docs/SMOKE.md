# スモークテスト チェックリスト (Smoke Test Scenarios)

> **対象**: 数学アプリ (`math/`) / 英語アプリ (`english/`) / ルートハブ  
> **基準コミット**: `cc07dcb` (`v1.8-baseline`)  
> **目的**: Phase 1〜6 のリファクタリング作業中、既存機能が破損していないかを迅速かつ機械的に検証する。

---

## 8大必須スモークシナリオ

| ID | シナリオ名 | 対象 | 手順 | 期待される結果 | 判定 | 備考 |
|---|---|---|---|---|:---:|---|
| **M1** | 多問題解説とタブ切替 | 数学 | 2問以上の問題画像またはテキストを入力し「AI先生に解説してもらう」を実行。タブ切替を行う。 | 2問とも独立したタブが生成され、タブ切替時に各問題の認識結果・着眼点・ステップ・答えが正しく切り替わる。 | [ ] | 独立DOM管理 |
| **M2** | 類題クイズ再利用 (API 0回) | 数学 | 解説完了後、「類題（4択クイズ）に挑戦」エリアを表示。 | 初回解説のレスポンスに含まれる `twin_quiz` がそのまま使われ、**追加の Gemini API コールが 0 回** であること。 | [ ] | APIコスト0 |
| **M3** | 4択ローカル採点 (API 0回) | 数学 | 類題クイズで誤答を選択し、判定を確認する。 | 即座にローカルで採点され、正解の選択肢・解説・ヒントが表示される。API 呼び出しは **0回**。 | [ ] | 完全ローカル |
| **M4** | ノート保存と復元 | 数学 | 「ノートに保存」をクリック後、履歴モーダルから復元する。 | 問題・ステップ・数式・図形・`overall_chat`(全体Q&A)・`stepChats`(ステップQ&A)が欠落なく復元される。 | [ ] | localStorage 保持 |
| **M5** | 全体Q&Aとタブ切替レース | 数学 | 2問解説後、問1で全体質問を送信し、回答受信前に問2タブへ切替。受信後に問1へ戻る。 | 回答が問2に漏れず、問1のチャット履歴にのみ正しく格納・表示される。タブ切替レースフリー。 | [ ] | 状態の単一性 |
| **M6** | リクエストキャッシュ (2回目 0回) | 数学 | 同一の問題画像/テキストを再度「AI先生に解説」で実行。 | API 呼び出しが行われず（または即時キャッシュ応答）、キャッシュから復元された旨が正しく通知される。 | [ ] | キャッシュ検証 |
| **M7** | 英語アプリ 主要フロー | 英語 | 英文を入力して「長文読解」を実行 → クイズ挑戦 → ノート保存 → 復元。 | 本文解説・語彙分解・クイズ（API 0回）・単語帳保存・ノート復元が一連でエラーなく動作する。 | [ ] | 英語アプリ独立 |
| **M8** | PWA動作とオフライン再訪 | PWA | PWAインストール（またはホーム画面追加）→ オフラインモード切替 → 再読込。 | キャッシュから正常にUIが描画され、オフラインでも過去ノートの閲覧が可能。新バージョン公開時にSW更新が反映される。 | [ ] | Service Worker |

## 各フェーズ別 実行要件

- **Phase 0 (基準線)**: 픽스처 8종 및 스텁으로 M1~M7 데이터 구조 검증 완료.
- **Phase 1 (허브 + math/ 이동)**: M1, M3, M4, M7, M8 우선 검증 (경로 404 없음 확인).
- **Phase 2 (셸 분리)**: M1, M3, M4, M7 콘솔 에러 0건 확인.
- **Phase 3 (파일 분해)**: 8개 항목 전체 검증.
- **Phase 4 (ESM + 이벤트 위임)**: 8개 항목 전체 + 모든 `[data-action]` 버튼 클릭 점검.
- **Phase 5 (core 추출)**: M1~M7 + 프롬프트/스키마 문자열 무변경 검증.
- **Phase 6 (테스트 완성)**: L1/L2 자동화 스위트 통과 + L3 수동 체크 서명.
